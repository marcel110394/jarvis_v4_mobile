Jarvis · Befehlsübersicht

Kurze Übersicht, was du Jarvis sagen kannst. Alle Befehle laufen über den KI-Core und landen in den Modulen (Kunden, Umsatz, Zeit, Mahnwesen, Projekte, Logbuch).

Kunden anlegen

Modul Kundenverwaltung · Intent: open_module

  • Lege Kunde (Trafik Steinweg) (Steinweg 20b) (4050) (Traun) (Max Mustermann) (office@trafik.at) (+43 660 123456)
    → Öffnet Kundenmaske mit allen Feldern vorausgefüllt (Name, Adresse, PLZ, Ort, Ansprechpartner, E-Mail, Telefon).
  • Öffne Kunden
    → springt direkt in die Kundenübersicht.

Umsatz & Großprojekte

Modul Umsatz / Großprojekte · Intents: add_revenue, open_big_projects

  • Umsatz 1500 für Tesla buchen
    → Eintrag in Umsatz mit Client „Tesla“.
  • Umsatz 3000 Euro auf Großprojekt P2025-ALPHA für ACME
    → Umsatz mit Projekt-ID verknüpft.
  • Öffne Großprojekte
    → Öffnet Großprojekte (Projekt-Board).

Zeiterfassung

Modul Zeit · Intent: add_time_entry

  • Buche 2,5 Stunden für ACME zum Satz 140
    → Legt einen Zeiteintrag an (Projekt, Stunden, Stundensatz).
  • Buche 5 Stunden auf Projekt P2025-ALPHA zum Satz 160
    → Zeitbuchung direkt auf eine Projekt-ID.
  • Öffne Zeit
    → Springt in das Zeiterfassungs-Modul.

Termine

Modul Termine · Intent: create_appointment

  • Termin 21.11.2025 14:00 Meeting mit Trafik Steinweg
    → Legt einen Kalendereintrag an (Datum, Uhrzeit, Titel).
  • Öffne Termine
    → Terminübersicht öffnen.

Mahnwesen

Modul Mahnwesen · Intent: create_dunning

  • Schreibe erste Mahnung für Rechnung RE-2025-004 über 1500 Euro an Trafik Steinweg, fällig am 10.11.2025
    → erzeugt Mahn-Datensatz (Level 1) und öffnet das Mahnwesen.
  • Öffne Mahnwesen
    → Liste aller Mahnungen.

Lager · Spesen · Umsatz

Module Lager / Spesen / Umsatz · Intents: scan_item, add_revenue

  • Scanne bitte den nächsten Artikel ins Lager
    → Aktiviert Lager-Scan-Modus und öffnet Lagerbestand.
  • Öffne Lager
    → Lagerbestands-UI.
  • Öffne Spesen
    → Spesen-Modul (manuelle Eingabe).
  • Öffne Umsatz
    → Umsatz-Dashboard (Rechnungen-Summen).

Dashboard · Logbuch

Module Dashboard / Logbuch · Intents: open_module

  • Öffne Dashboard
    → Gesamtübersicht (KPIs, Links).
  • Öffne Logbuch
    → System-Logbuch (missionLogs, Umsatz-Events, Backups).

Standard · Hilfe

Core KI-Core · Intents: greeting, help, fallback_command

  • Servus Jarvis
    → Kurze Status-Antwort (Online / Ready).
  • Hilfe
    → Jarvis beschreibt kurz, was er alles kann.
  • Öffne Befehle
    → Diese Befehlsübersicht (wenn du später im Backend „commands.html“ mit mappst).
